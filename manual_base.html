1つの円の点を、花びらの輪郭（XZ平面）に並べ替える。全 6 ステップ。
Re-places the points of a circle into a flat petal outline on the XZ plane, in 6 steps.

日本語
UI のパラメータを受け取る。右の図は、それぞれが花びらのどこを決めるかのイメージ。
max_width / root_width / tip_width は、どれも左端から右端までの全幅。左右に振り分けるため、あとの計算ではそれぞれ半分（/ 2）にして片側の幅として使う。
width_curve は幅の変化のカーブ。root_curve / tip_curve は長さ方向の進み方のカーブ（ステップ 5 で使う）。
English
Read the parameters from the UI. The figure shows which part of the petal each one controls.
max_width, root_width and tip_width are all full widths, from the left edge to the right edge. Later each one is halved (/ 2) so it can be used as a one-sided width and split between left and right.
width_curve eases the width change; root_curve / tip_curve ease the progress along the length (used in step 5).

輪郭上の位置を決める（u と t）
Where are we on the outline? (u and t)
f@curveu = float(@ptnum) / float(@numpt - 1);
float u = @curveu;
// Root → Tip
float t = 0.5 * (1.0 - cos(u * 2.0 * M_PI));
全文で見る ↓ See in full code
日本語
① 輪郭の点に、最初が 0・最後が 1 の通し番号 u をつける。
② u を t に変換する。u が 0 → 0.5 → 1 と進むと、t は 0 → 1 → 0（付け根 → 先端 → 付け根）。
左右の辺が同じ t を通るので、左右対称の形になる。
English
① Give every outline point a running value u: 0 for the first point, 1 for the last.
② Convert u into t. As u runs 0 → 0.5 → 1, t runs 0 → 1 → 0 (root → tip → root).
Both edges pass through the same t values, so the shape is symmetric.

幅を計算する
Compute the width
// Calculate width
float width;
if (t <= max_width_pos)
{
float local_t = fit(t, 0.0, max_width_pos, 0.0, 1.0);
local_t = smooth(0.0, 1.0, pow(local_t, width_curve));
width = lerp(root_width/2, max_width/2, local_t);
}
else
{
float local_t = fit(t, max_width_pos, 1.0, 0.0, 1.0);
local_t = smooth(0.0, 1.0, pow(local_t, width_curve));
width = lerp(max_width/2, tip_width/2, local_t);
}
全文で見る ↓ See in full code
日本語
t が max_width_pos 以下（前半）と、それより大きい（後半）で、同じ手順を 2 回行う。
① fit：区間を 0〜1 に引き伸ばす（local_t）
② pow：width_curve でカーブをつける
③ smooth：なめらかな 0→1 にする
④ lerp：前半は root_width/2 → max_width/2、後半は max_width/2 → tip_width/2（3つとも全幅の値なので、半分にして片側の幅にそろえる）
メモ：max_width_pos は 0 より大きく 1 より小さい値で使う。ちょうど 0 や 1 だと、前半か後半の区間の長さが 0 になって、fit の範囲が潰れてしまう。
English
The same steps run twice: while t ≤ max_width_pos (first half), and after it (second half).
① fit: stretch the range to 0–1 (local_t)
② pow: bend it with width_curve
③ smooth: turn it into an eased 0 → 1
④ lerp: root_width/2 → max_width/2 in the first half, max_width/2 → tip_width/2 in the second (all three are full widths, so each is halved to match the one-sided width)
Note: keep max_width_pos strictly between 0 and 1. At exactly 0 or 1, one of the two ranges has zero length and the fit range collapses.
5
長さ方向の位置 z を計算する
Compute the position along the length (z)
// Calculate curve
float z;
if (t <= max_width_pos)
{
float local_t = fit(t, 0.0, max_width_pos, 0.0, 1.0);
float curve_power = max(0.1, 1.0 + root_curve);
local_t = pow(local_t, curve_power);
z = local_t * max_width_pos * length;
}
else
{
float local_t = fit(t, max_width_pos, 1.0, 0.0, 1.0);
float curve_power = max(0.1, 1.0 + tip_curve);
local_t = smooth(0.0, 1.0, pow(local_t, curve_power));
z = (max_width_pos + local_t * (1.0 - max_width_pos)) * length;
}
全文で見る ↓ See in full code
日本語
幅と同じ 2 区間構成。curve_power ＝ 1 + curve（max で 0.1 以上）。
前半：z = local_t × max_width_pos × length（smooth なし）
後半：z = (max_width_pos + local_t × (1 − max_width_pos)) × length（smooth あり）
curve が 0 なら等間隔、プラスなら出だしがゆっくり、マイナスなら出だしが速い。
English
Two ranges again, like the width. curve_power = 1 + curve, floored at 0.1 with max.
First half: z = local_t × max_width_pos × length (no smooth)
Second half: z = (max_width_pos + local_t × (1 − max_width_pos)) × length (with smooth)
curve = 0 gives even spacing; positive starts slowly, negative starts fast.

座標を書き込む
Write the position
float x = side * width;
@P = set(x, 0, z);
全文で見る ↓ See in full code
日本語
x = side × width で、幅を左右に振り分ける。
y は 0 のままなので、花びらは XZ 平面にぺたんと置かれる。
@P = (x, 0, z) で、輪郭の点がすべて新しい位置に移動して完成。
English
x = side × width pushes the width left or right.
y stays 0, so the petal lies flat on the XZ plane.
@P = (x, 0, z) moves every outline point to its new place — the outline is done.
