日本語
notch_depth：切れ込みの深さ。先端の点を付け根側（−Z）へ下げる量。
notch_direction：切れ込みの横ずれ。先端の点を −X 側へずらす量（マイナスなら +X 側）。
notch_width：肩の広がり。先端のまわりの点を外側へ広げる量。
notch_range：肩を広げる範囲。先端（u = 0.5）からの u の差がこの値より小さい点が動く（ステップ 4）。
図は先端まわりの拡大イメージ。点線がもとの輪郭。
English
notch_depth: how deep the cleft is, i.e. how far the tip point moves toward the root (−Z).
notch_direction: sideways shift of the cleft; the tip point moves toward −X (toward +X if negative).
notch_width: how far the shoulders spread, i.e. how far the points around the tip move outward.
notch_range: how wide the shoulder area is. Points whose u is closer to the tip (u = 0.5) than this value move (step 4).
The figure is a close-up of the tip. The dashed line is the original outline.

日本語
Fix Curveu が保存した Detail アトリビュート tip_pt（先端の点番号）を detail() で読む。先端を探しなおす必要はない。
hasdetailattrib は保険。tip_pt が保存されていないときは return して、何も動かさない。
tip_P は先端の位置。@P.x − tip_P.x の符号で、先端より右（+1）か左（−1）かを決める。先端自身は 0。
メモ：side は先端を動かす前に計算しておく。先に動かすと、先端より左右がずれた位置で判定してしまう。また x = 0 ではなく先端の x を基準にしているので、noise や notch_direction で先端が中心からずれても左右を正しく分けられる。
English
Read the Detail attribute tip_pt (the tip’s point number) saved by Fix Curveu with detail(). No need to search for the tip again.
hasdetailattrib is a safety net: if tip_pt was never saved, return and move nothing.
tip_P is the tip position. The sign of @P.x − tip_P.x says whether the point is right (+1) or left (−1) of the tip. The tip itself gets 0.
Note: side is worked out before the tip moves; moving first would shift the reference. And because it is measured from the tip’s x instead of x = 0, left and right stay correct even when noise or notch_direction moves the tip off-center.

English
Only the tip point moves (@ptnum == tip_pt).
z goes down by notch_depth → the tip sinks toward the root and becomes the bottom of a V.
x goes down by notch_direction → the V shifts toward −X (toward +X for negative values).

日本語
先端以外の点はこちら。d は先端（u = 0.5）からの u の差。
smooth(0.0, notch_range, d) は、d が 0 → notch_range で 0 → 1 になめらかに増える。それを 1.0 − で反転して、先端に近いほど 1、notch_range より遠いと 0 になる weight を作る。
ステップ 2 の side の向きに、notch_width × weight だけ外側へ広げる。谷の両側が「肩」のように張り出して、V 字がはっきりする。
メモ：u の距離で決めているので、resample1 の点の間隔を変えても、切れ込みの幅は変わらない。notch_range は 0 より大きい値で使う（点が 100 個くらいなら、となりの点との u の差はおよそ 0.01）。
English
Every point except the tip comes here. d is how far its u is from the tip (u = 0.5).
smooth(0.0, notch_range, d) eases from 0 to 1 as d goes from 0 to notch_range. 1.0 − flips it, so weight is 1 near the tip and 0 beyond notch_range.
The point moves outward along side (step 2) by notch_width × weight. Both sides of the V bulge out as "shoulders", so the cleft reads clearly.
Note: Because it uses distance in u, changing the point spacing in resample1 does not change the cleft’s width. Keep notch_range above 0 (with about 100 points, neighboring points are roughly 0.01 apart in u).
