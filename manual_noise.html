日本語
asymmetry：左右の幅の差の強さ（ステップ 2）。
_l は大きいノイズ（large）、_s は小さいノイズ（small）用。同じセットが 2 組ある。

English
asymmetry: how strongly the left and right widths differ (step 2).
_l is for the large noise and _s for the small noise: the same set of controls, twice.
amplitude: how far the outline moves. frequency: how fine the noise is (higher = more waves). offset: slides the noise pattern (for variations).
u = @curveu: the position along the outline set up by fix_curveu (root 0 → tip 0.5 → root 1).
2
左右を非対称にする
Make it asymmetric
// Asymmetry
float side = sin(u * 2.0 * M_PI);
@P.x *= 1.0 + side * asymmetry;
全文で見る ↓ See in full code
日本語
sin(u × 2π) は、u が 0 → 0.25 → 0.5 → 0.75 → 1 と進むと、0 → 1 → 0 → −1 → 0 になる。
前半（片側の辺）はプラス、後半（もう片側の辺）はマイナス。
x に (1 + side × asymmetry) を掛けるので、片側は広がり、もう片側は狭まる。付け根と先端は side が 0 なので動かない。
メモ：ここの side は base の side（±1 の向き）とは別もので、−1 〜 1 のなめらかな値。
English
sin(u × 2π) runs 0 → 1 → 0 → −1 → 0 as u runs 0 → 0.25 → 0.5 → 0.75 → 1.
It is positive on the first half (one edge) and negative on the second half (the other edge).
x is multiplied by (1 + side × asymmetry), so one side gets wider and the other narrower. The root and tip have side = 0, so they stay put.
Note: This side is not the same as side in Base (the ±1 direction): here it is a smooth value from −1 to 1.
3
外向きの方向を求める
Find the outward direction
// Get outward
int prev = (@ptnum - 1 + @numpt) % @numpt;
int next = (@ptnum + 1) % @numpt;
vector P_prev = point(0, "P", prev);
vector P_next = point(0, "P", next);
vector tangent = normalize(P_next - P_prev);
vector N_prim = prim_normal(0, 0, {0.5, 0.5});
vector outward = normalize(cross(tangent, N_prim));
全文で見る ↓ See in full code
日本語
① 前後の点 prev / next を求める。% @numpt で、最初と最後の点がつながる（閉じた輪郭）。
② tangent：next − prev の向き＝輪郭に沿った向き（接線）。
③ N_prim：輪郭ポリゴンの面の法線。花びらは XZ 平面にあるので、真上か真下（±Y）を向く。
④ cross(tangent, N_prim)：2 つの両方に垂直な向き＝XZ 平面の中で、輪郭に垂直な向き。これが outward。
メモ：点の並び順（巻き方向）は輪郭全体で同じなので、全部の点が同じ側（外側）を向く。点ごとの反転チェックはいらない。もし全部内向きになったら、cross(N_prim, tangent) と順番を入れ替える。
English
① Find the neighbors prev / next. % @numpt joins the first and last points (a closed outline).
② tangent: the direction next − prev, i.e. along the outline.
③ N_prim: the face normal of the outline polygon. The petal lies in the XZ plane, so it points straight up or down (±Y).
④ cross(tangent, N_prim): perpendicular to both, i.e. perpendicular to the outline inside the XZ plane. This is outward.
Note: The point order (winding) is the same all around the outline, so every point faces the same side (outward). No per-point flip check is needed. If they all face inward, swap the order: cross(N_prim, tangent).
4
大きいノイズ
Large noise
// Large Noise
vector pos_l = set(
cos(u * 2.0 * M_PI) * scale_l,
sin(u * 2.0 * M_PI) * scale_l,
0
) + offset_l;
float n_l = noise(pos_l);
@P += outward * (n_l - 0.5) * noise_l;
全文で見る ↓ See in full code
日本語
u を円の上の座標 (cos, sin) に変えて、ノイズ空間の円をひとまわりするように noise を読む。
u = 0 と u = 1 が同じ場所になるので、付け根の継ぎ目でノイズが途切れない。
frequency_l は円の半径。大きいほど広い範囲を読むので、波が細かくなる。offset_l で円の位置をずらすと模様が変わる。
noise() はだいたい 0〜1 の値なので、− 0.5 してプラス・マイナスに振り、outward の向きに amplitude_l 倍だけ押し出す・引っ込める。
English
u is turned into a point (cos, sin) on a circle, so noise is read while going once around a circle in noise space.
u = 0 and u = 1 land on the same spot, so there is no break in the noise at the root seam.
frequency_l is the circle’s radius: a bigger circle covers more of the noise, so the waves get finer. offset_l moves the circle and changes the pattern.
noise() returns roughly 0–1, so − 0.5 makes it plus/minus, and the point is pushed out or pulled in along outward by amplitude_l.
